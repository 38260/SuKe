# SuKe 路线图

> 本文为 [Roadmap.md](../../Roadmap.md) 的中文翻译。若中英文出现歧义，以英文原文为准。

SuKe 始终专注于「可靠的本地工作区采集与恢复」。它与 PowerToys Workspaces 的区别在于：它会保留受支持的应用、文件、文件夹、浏览器、资源管理器标签页、终端标签页以及虚拟桌面上下文。

详细的工单历史保存在私有规划仓库中。这份公开路线图只列出「已发布的内容」与「当前正在推进的一小段流水线」。

## 当前版本：v1.7.0 — Desktop Context

1.7.0 新增：

- Windows 终端标签页的配置文件（profile）、起始目录、顺序与激活标签页恢复，借助可选的 PowerShell 集成与「保存时编辑器」实现。
- 跨 Windows 虚拟桌面的自动采集、缺失桌面的重建，以及把已存在或新启动的窗口放到其保存时所在的桌面。
- ATLauncher 改为通过其稳定的启动器启动，而不再用不带必需命令行的裸 Java 运行时命令。
- 在分辨率稳定、扩展坞变化或显示器临时异常之后，进行临时显示恢复。
- 对「允许启动/桌面移动但拒绝几何变更」的应用给出非致命诊断。

同时包含 v1.6.x 的资源管理器多标签页、浏览器配置文件、匹配、恢复、诊断与自适应布局相关工作。

## 进行中的流水线

1. **检查点与撤销验证（WA-006A）**——完成真实 Windows 下的 Restore、Exact Switch、Undo 以及「撤销的撤销」核对清单。
确定性的恢复仿真装置矩阵（WA-046）已完成：合成输入覆盖显示器映射、匹配、混合 DPI、浏览器/PWA 身份、VS Code 项目、不可用资源与逻辑路径别名，且不会改动真实桌面。

本地工作区导入/导出（WA-033）已完成：带版本号的「精确」或「可移植/脱敏」文件，提供显式元数据选择、分阶段冲突预览、v1 传输格式迁移与原子化的本地副本导入——不涉及账号、云同步或自动跨设备合并。

当前使用与连接器安装说明见 [项目说明](../../README.md)。历史分发记录不代表本项目已发布商店版本或签名包。

## 不在当前路线图内

跨设备恢复、云同步、社区模板/配方、通用自动化引擎、按计划或解锁触发的桌面变更、音频/设备配置、显示器模式切换，以及公开兼容性数据库，都不是当前的产品承诺。其历史规划记录仅为可追溯性而保留。

## 发布质量门槛

每个版本都必须满足：保持窗口与其保存条目的一对一分配；拒绝过期的破坏性意图；不把用户隐私内容写入日志；在不丢数据的前提下迁移旧版存储；通过 Release 测试套件；发布带标签的产物并附上匹配的 SHA-256 校验和。依赖真实 Windows 应用的功能，在被描述为「已验证」之前，还必须有一段真实环境冒烟测试记录。
