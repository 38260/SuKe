# SuKe v1.7.0 — Desktop Context

> 本文为 [release-notes.md](../../release-notes.md) 的中文翻译。若中英文出现歧义，以英文原文为准。

## 概述

SuKe 1.7.0 让工作区上下文可以跨 Windows 终端标签页与 Windows 虚拟桌面恢复。同时新增了临时显示恢复，以及针对「正常进程/归属模型无法通用恢复」的应用的定向兼容处理。

## 亮点

- 采集终端标签页，含其 PowerShell 配置文件、当前目录、顺序与激活标签页。
- 保存前可复核或修正终端标签页元数据；用一条受支持的 `wt` 命令恢复整套标签页。
- 采集当前所有 Windows 虚拟桌面上的合格应用，并在 Save Workspace 中按桌面与显示器分组展示。
- 重建缺失的虚拟桌面，把已存在或新启动的窗口送回其保存时所在的桌面，且不删除多余桌面、不切换当前可见桌面。
- ATLauncher 改为通过 `ATLauncher.exe` 启动，而不是在缺少必需命令行参数的情况下启动其自带的 `javaw.exe`。
- 在显示器临时变化并稳定后恢复已保存布局，支持「先询问」「禁用」「自动+检查点」三种行为。
- 提权的 IObit 在启动与桌面放置成功后若拒绝几何变更，按非致命限制处理。

## 兼容性与迁移

- 工作区 schema v11 存储了有序的虚拟桌面拓扑与逐条目的桌面归属。更早的工作区仍可正常加载，只是不包含可重建的拓扑信息。
- 原有设置继续可用；已废弃的「虚拟桌面 opt-in」开关会被忽略，因为采集与恢复现在自动跟随已保存的工作区数据。
- 早期原型创建的终端工作区不包含可信的逐标签页数据，应重新采集。
- Windows Shell 私有路径按构建选定，覆盖 Windows 11 23H2 与 24H2/25H2。不受支持的版本只会跳过拓扑操作，窗口仍保持可访问。

## 验证

- Release 测试 371/371 通过，无失败、无跳过。
- 真实环境完成一次「两标签页 Windows 终端」往返恢复，还原了不同的目录与标签页选择。
- 一次可逆的真实桌面冒烟测试：创建桌面、移动受控窗口、验证归属、送回原处、删除临时桌面。
- 一次完整的工作区恢复重建了桌面 2，并把 IObit 与两个 ATLauncher 窗口恢复到其上；当桌面 2 已存在时，同一恢复同样通过。
- 此前的 Windows 11 25H2 资源管理器三标签页冒烟测试仍在覆盖范围内。

## 发布产物

- `SuKe-v1.7.0.exe` — 自包含的 Windows x64 应用。
- `SuKe-Browser-Connector-v1.7.0.zip` — 可选 Chromium 连接器。
- `SuKe-Firefox-Connector-AMO-v1.7.0.zip` — 未签名的 Firefox 评审/开发包。
- `SuKe-Terminal-Integration-v1.7.0.ps1` — 可选 PowerShell 提示符集成。
- `SHA256SUMS.txt` — 所有带版本号产物的校验和。

当前使用与连接器安装说明见 [项目说明](../../README.md)。历史分发记录不代表本项目已发布商店版本或签名包。

## 升级

1. 从托盘菜单退出 SuKe。
2. 下载本 Release 的 `SuKe-v1.7.0.exe` 并校验其校验和。
3. 替换旧的可执行文件，或直接运行新文件。
4. `%AppData%\SuKe` 下的既有数据会自动迁移。
