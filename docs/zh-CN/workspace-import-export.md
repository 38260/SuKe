# 工作区导入与导出

> 本文为 [docs/workspace-import-export.md](../workspace-import-export.md) 的中文翻译。标识符、文件名与 UI 元素名保持原样；若中英文出现歧义，以英文原文为准。

SuKe 一次只传输一个已保存的工作区。它绝不导出整个应用配置、设置、别名根映射、凭据、Cookie、文档内容或浏览器原生 host 注册数据。

## 导出

在 **Settings → Saved Workspaces** 中打开某个工作区的 **…** 菜单，选择 **Export…**。选择目标位置以及要包含的元数据类别。

- **Exact backup（精确备份）** 从「所有已选中的工作区元数据」开始，包括本地布局与路径。当其中包含文件位置或浏览器 URL 时，请把生成的 `.suke.json` 文件保持私密。
- **Portable / redacted（可移植/脱敏）** 起始时不包含布局、文件/文件夹、浏览器 URL、机器标识符或绝对本地路径。它可以保留逻辑 `${ALIAS}` 路径形式，但绝不导出分配给别名的本地根路径。

类别开关让你可以包含或排除布局、应用身份、文件/文件夹、浏览器 URL、机器标识符与逻辑别名。禁用一个类别就会从文件中移除该类数据。可移植导出即使在保留应用身份的情况下，也总会移除原始的绝对回退路径。

## 导入

在同一个 Settings 区域选择 **Import Workspace**，并选择一个本地 `.suke.json` 文件。SuKe 会先分阶段暂存并校验它，然后展示一个预览，包含工作区名称、窗口数量、传输模式、迁移状态，以及任何名称/稳定 ID 冲突。

导入总是创建一个独立副本。匹配到的稳定 ID 会被替换为新 ID；匹配到的显示名会获得 `Imported` 后缀。已存在的工作区绝不会被覆盖。文件在预览之后会再次被校验，因此若文件已改变，必须重新复核后才能导入。

传输文件限制为 5 MB。当前导出使用传输 schema v2；schema v1 文件与更旧的受支持工作区负载会在分阶段暂存期间迁移。未来版本或格式错误的 schema 会被拒绝，且不写入工作区存储。最终导入的文档使用常规的原子工作区仓储，因此一次失败的提交会让既有工作区保持完好。

导入一个工作区不会启动或恢复任何应用。请在复核其已保存元数据之后，单独恢复这个新工作区。
