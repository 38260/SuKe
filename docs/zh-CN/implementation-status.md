## 已实现并验证

| 能力 | 证据 |
|---|---|
| 恢复规划、匹配、模式、预览、就绪、放置、检查点与诊断 | 确定性服务测试覆盖歧义、过期、取消、单 HWND 归属、检查点持久性、条件式预览/检查点、DPI 感知适配、有界放置校验与脱敏。Undo 与「撤销的撤销」走同一条 Exact Switch 对账路径，且一次失败的强制 Undo 检查点不会发出任何关闭请求。 |
| 文件资源管理器标签页 | 自动化覆盖，外加一次隔离环境下的 Windows 11 25H2 三标签页恢复、激活标签页选择，以及重跑时零重复。 |
| Windows 终端标签页（WA-021） | 自动化采集/规划覆盖，外加一次真实的双标签页往返（不同目录与激活项）。可选的 PowerShell 集成随发布包一起分发。 |
| 虚拟桌面（WA-022/WA-048） | 自动化拓扑映射，外加真实的「非活动桌面采集、临时创建/移动/返回/删除桌面」，以及完整的「已删除/已存在桌面 2 工作区恢复」（使用 IObit 与 ATLauncher）。 |
| 临时显示恢复（WA-030B） | 合成稳定化、仅在回归时触发、重复抑制、全屏延迟与检查点闸门均通过。一次真实的扩展坞/分辨率冒烟仍是有用的发布校验。 |
| 应用适配器 | Chromium PWA、专用浏览器、资源管理器、终端、VS Code、ATLauncher、IObit 放置策略与通用回退都有针对性测试。 |
| 恢复仿真（WA-046） | 八个带版本号、已脱敏的规划器装置，覆盖拓扑映射、匹配、DPI、浏览器/PWA、VS Code、缺失资源与路径别名；损坏输入在规划之前即被拒绝。 |
| 本地工作区导入/导出（WA-033） | Settings 提供按类别控制的「精确」或「可移植/脱敏」导出，以及分阶段的本地导入预览。稳定 ID/名称冲突总会创建副本；transfer v1 与更旧的受支持工作区负载会在原子保存之前完成迁移。 |
